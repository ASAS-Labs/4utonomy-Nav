## Project Scope

**4utonomy Nav** is a comprehensive autonomous vehicle platform including:

1. **Navigation System**
   - Based on Autoware open-source platform
   - Real-time localization and mapping
   - Path planning and control

2. **Operational Risk Assessment System** (NEW - 2026)
   - Real-time weather impact analysis
   - Sensor health monitoring
   - Operational domain compliance
   - Multi-factor risk aggregation
   - Safety recommendations

3. **Weather Intelligence Integration**
   - Complements external weather APIs (Google Weather API, Zoom.earth)
   - Adds AV-specific sensor impact models
   - Translates weather data to operational decisions
